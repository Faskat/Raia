# Raia

Исторический прототип голосового помощника для Windows на Python. Код содержит
распознавание команд, ответы голосом, открытие программ и управление процессами.
Статус: незавершённый прототип; воспроизводимая установка не подготовлена.

В `Raia/main.py` используются отсутствующие в репозитории модули `stt`, `tts`
и `num2t4ru`, а также `fuzzywuzzy` и `psutil`. Нет файла зависимостей и тестов.
Проверить синтаксис без запуска помощника можно командой
`python -m compileall -q Raia` (Python 3.12).

Полноценная команда запуска пока не документирована: прежде нужны реализации
STT/TTS и настройка путей программ. Команды сна компьютера и завершения процессов
выполняются непосредственно после распознавания; перед возобновлением разработки
нужны подтверждение таких действий и тесты на имитациях. Скриншота рабочего
интерфейса нет. Этот репозиторий не обозначает актуальный готовый продукт.
